# 材料版本与案件证据工作台

| 功能 | 规则 | 业务入口 |
|---|---|---|
| 材料版本 | 当前原件追加新版本；旧原件不覆盖，最多 50 版；版本竞争返回冲突 | 接入材料 → 版本历史 → 追加新版本 |
| 审核失效 | 新版本改变关联摘要，旧关联/验收失效；历史材料禁止重新提案 | 证据关联与案例验收 |
| 证据工作台 | 按租户案件展示全部账簿来源、最新 100 条材料关联和付款/退款分别差额 | 证据工作台 → 输入案件 |
| 核验建议 | 默认明确标识规则建议；可选择本租户已测试的真实模型，仅为辅助 | 生成核验建议 |
| 核验任务 | 用户确认后创建，来源与当前摘要绑定；重复请求不复制任务 | 创建核验任务 |
| 处理记录 | 保存授权处理引用，只关闭任务，不修复证据、不批准验收 | 记录处理结果 |

大模型经既有 Model Gateway 的真实模式、出网/预算/超时约束和租户密钥服务调用。每次请求需明确允许发送脱敏检查状态，只发送来源编号、通用检查标签、通过状态及通用缺口描述；不发送材料原文、金额、客户编号和外部记录引用。返回必须符合限定 JSON 格式并引用本次已有缺口来源。模型建议不能写入账簿、改验签、批准审核或直接创建任务；调用失败显示错误，不能伪装为模型成功。

材料原件仍支持 CSV/PDF/PNG/JPG，CSV 自动按三字段核对，PDF/图像留存并由人工核验。高级 OCR、客户专有连接器和自主外呼不属于本轮交付。软件功能与客户生产试点状态分开记录。

工作台每次读取或导出重新核对当前证据，切换案件/租户和请求失败清除旧结果。旧任务在证据变化后显示失效，不能继续登记处理；需从当前快照创建新任务。建议不保存模型原文，仅审计模式、摘要和来源引用。部署迁移 033。升级后关联摘要加入版本状态，已有审核需要刷新复核，不能继续使用旧摘要批准。

模型侧来源编号使用每次请求随机生成的别名，禁止发送持久材料 ID；校验响应别名后，服务端映射回工作台来源引用。只有历史材料时明确提示缺少当前材料关联，可创建补证任务。
