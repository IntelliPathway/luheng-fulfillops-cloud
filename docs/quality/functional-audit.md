# v4.15 功能可用性修复与验收

## 范围与交付边界

检查 15 个主页面、客户接入六个子流程和活动详情。版本保持 v4.15，不拆分新版本。
Sites 当前仍是未配置独立 FastAPI / OIDC 的前端演示站点；本次不虚构生产后端、凭据或客户材料。
真实模型、外呼、客户同步和资金操作必须具备独立部署的后端及对应授权。功能修复与客户生产验收分开记录。

## 发现并修复

| 问题 | 原行为 | 修复后的可验证行为 |
|---|---|---|
| AI 指挥台未接入时整页隐藏 | 只剩“需要连接业务 API” | 页面内指令查询、演示保护依据、活动草案与四个业务入口可用；真实审批与联系说明接入条件 |
| 指挥台接口耦合 | 管理员接口拒绝或任何接口失败使全部模块不可读 | 运营角色不请求管理员接口；独立加载，失败模块清空并显示错误，其余模块继续可用 |
| AI 提交与租户隔离 | 重复提交、切换租户后旧回答可能保留 | 提交锁、作用域失效、旧响应忽略，连接失败不回退演示回答 |
| Agent 提案重复执行 | 确认提案后再直接发活动状态变更 | 只确认一次，状态重新读取服务端；不二次执行，不追加本地伪审计 |
| 在线 Agent 详情使用样本步骤 | 固定完成步骤、日期、应还金额与成本 | 读取活动范围、账簿与持久化活动会话 Run；无记录显示未执行，成本归因缺失明确说明 |
| 策略实验只有 API / 列表 | 无创建、启动、停止、统计入口 | 表单提交草稿，独立管理员确认启动，停止与分组统计可操作；不声称自动切换执行策略 |
| 租户生命周期仅展示 | API 支持提案 / 复核，页面无入口 | 版本化变更提案、独立批准 / 驳回，权限和不可逆关闭说明 |
| 策略评估伪通过 | 前后端写死 25/25 | 参数检查明确标识，场景数为 0、未执行回放；旧无类型报告标记未核验，不沿用虚假通过数 |
| 策略状态硬编码 | 草稿也显示已发布 | 使用资产包当前服务端策略状态 |
| 审计 / 知识 / 评测读失败 | 旧数据保留，错误仅短暂通知 | 清空旧数据、显示页面错误，审计失败禁用导出并支持重新读取 |
| 用量失败显示演示数字 | 在线失败显示 18 Run / 146 次 / 固定成本 | 未取得数据显示“—”，显式错误与重试；只在明确演示模式显示样本 |
| 启动时未完成核心读取 | 连接检查阶段即可操作；账务失败可能显示零 | 连接检查期间不开放业务界面；账务 / 保护 / 协议读取失败阻止启动 |
| 组织名称“保存”含义错误 | 只改会话状态却提示组织资料已保存 | 标明本次会话显示别名，不宣称企业资料持久化 |
| 联系编排门禁 | 无可用渠道也能提交；时间按 UTC 填本地控件 | 无当前可用渠道不能提交，输入使用本地时间再转 UTC；取消后不再显示停止按钮 |

## 全页面检查矩阵

| 页面 / 流程 | 未接入时可用 | 真实业务依赖及限制 |
|---|---|---|
| 运营总览 | 演示指标、图表、对象跳转 | 在线趋势和财务来自账簿，失败不替换演示 |
| AI 指挥台 | 规则查询、证据、草案、业务跳转 | 服务端会话、审批、联系依赖 API；演示不伪造执行 |
| 试点验收 | 接入条件和诊断说明、各接入表单结构 | 技术预检和真实验收必须读取后端 |
| 履约活动 | 沙箱创建、运行、暂停与恢复 | 线上活动由服务端重新预检与状态机裁决 |
| 资产包 / 案件 | 演示筛选、分页、详情 | 线上导入与目录由租户 API 提供 |
| 协议履约 | 样本方案与期次核对 | 提案、独立批准、分配以服务端为准 |
| 回款与佣金 | 模拟回执与差额核对 | 真实验签 / 账簿 / 对账依赖业务 API，不允许本地替代写入 |
| Agents / 活动详情 | 明确标注的模拟步骤 | 在线只展示持久化 Run 和真实范围事实，无活动成本归因时不编造 |
| 异常中心 | 样本保护依据、演示工单 | 真实解除须独立复核，永久停止联系不能通用解除 |
| 运行记录 | 演示事件与导出 | 线上审计错误清空旧数据并禁用导出 |
| 策略与知识 | 样本参数、政策包、查询 | 新知识、策略实验、评测依赖服务端；参数检查不是模型 / 场景回放 |
| AI 与渠道 | 本地演示连接 / 门禁流程 | 沙箱契约不代表真实 Provider 接通；正式启用需凭据及独立测试 |
| 用量与账单 | 标明演示估算 | 线上计量必须读取服务端，账单预览不扣款 |
| 组织设置 | 会话别名与通知偏好 | 生命周期提案 / 独立复核依赖管理员与后端 |
| 客户连接器 / 材料 / 同步 / 关联 / 工作台 / 验收 | 接入说明与禁用原因 | 无 API / 密钥 / 客户授权时不上传、不伪造同步或签名事实 |

## 验证

- 后端：全套单元 / 集成回归，新增持久化 Run 的租户、会话所有者、活动范围与分页限额检查。
- 浏览器：保留已有生产接入、客户证据、账务、布局回归；新增演示全页巡检、AI 查询与失败恢复、运营角色、模块故障隔离、迟到响应、用量故障、审计清空、策略实验、生命周期、提案单次执行、真实 Run 与新表单移动布局。
- 视觉：主页面宽度 1440 / 1024 / 768 / 390 / 320；指挥台演示 1440 / 390 / 320；实验和生命周期表单 320。保留浏览器截图工件供人工检查。
- 构建与 Sites Worker 契约必须通过；不能用成功构建替代浏览器功能验证。

## 尚需客户环境提供

生产后端 / PostgreSQL / Worker、企业 OIDC、客户授权接口与材料、模型 / 渠道凭据。缺少这些条件时，真实执行仍被正确阻断；本轮合成数据和开发身份验证不代表真实客户验收。
