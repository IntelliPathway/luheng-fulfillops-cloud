## 运行检查

运行 `PYTHON_BIN=<python> bash scripts/verify.sh` 及 `npm run test:browser`。完整 PostgreSQL 测试需 `TEST_POSTGRES_URL` 和 `PG_RECOVERY_CONTAINER`，由 CI 隔离服务提供。浏览器启动额外的本地 QA 适配器，读取实际构建 Worker 与静态资源，不代理业务 API。它不部署到正式环境。

集成端点 `/api/v1/pilot/integration-acceptance` 只读、租户限定、no-store，报告版本为 1。摘要覆盖响应中去掉 report_digest 后的排序 JSON；下载时重新核验，旧副本只代表其生成时的快照。四项联合门禁全满足才显示可进入受控试点。任何报告都不启用外部执行。

## 生产接入未完成的事项

当前已发布 Site 未配置独立业务 API 和企业 OIDC，也没有客户授权材料、真实模型/通信/支付凭据。本轮完成软件集成与发布包验证，生产验收仍被门禁阻止。备份演练是合成数据库，不代替客户 RPO/RTO、真实密钥托管、告警投递与灾备审批。
