# v1.0 人工确认备忘录

| 优先级 | 确认项 | 需提供或决定 | 影响 |
|---|---|---|---|
| P0 | 企业身份 | OIDC issuer、audience、JWKS URL、client ID、回调/登出 URL，以及用户与租户成员映射 | 生产登录与权限 |
| P0 | 域名与 HTTPS | 生产域名、DNS、证书、反向代理与 CORS 白名单 | 安全访问与回调 |
| P0 | 租户开通 | 真实租户、管理员、运营员、观察员名单及角色审批 | 数据隔离与 Maker–Checker |
| P0 | 试点数据 | 脱敏资产样本、字段映射、数据保留周期和 PII 处理依据 | 数据导入与合规验收 |
| P0 | 合规批准 | 联系时段、频次、停止联系、录音、告知语和人工接管规则 | 真实触达资格 |
| P1 | 电话 Provider | Provider/SIP Trunk、沙箱号码、主叫号、回调白名单、验签密钥 | 电话事件联调 |
| P1 | 语音服务 | ASR/TTS Provider、区域、凭据、声音和数据留存设置 | 语音体验 |
| P1 | 模型 Provider | Endpoint/模型白名单、租户凭据、单次与每日预算，以及真实调用启用批准 | live-provider 回放与 Agent 调用 |
| P1 | 支付 Provider | Webhook 凭据、回调网络、金额上限和真实银行/收单机构 | 真实回款入账 |
| P1 | 运行资源 | ECS/容器容量、PostgreSQL、备份、监控、告警与密钥后端 | 生产部署 |

## 已记录的决策

- `v0.19` ECS/1Panel 生产部署本轮延后；代码和部署模板保留。
- 在上述事项确认前，真实模型、支付、电话和语音动作保持关闭。
- 人工确认应在相应联调或生产启用前完成，不阻断 v1.0 代码验证。
