## 已记录的决策

- `v0.19` ECS/1Panel 生产部署本轮延后；代码和部署模板保留。
- 在上述事项确认前，真实模型、支付、电话和语音动作保持关闭。
- 人工确认应在相应联调或生产启用前完成，不阻断 v5.0 软件开发与验证。

本轮不以合成账号冒充真实人员，不以模板完成冒充服务已运行。浏览器运行依赖下载失败，新增浏览器回归已编写但本环境尚未执行；生产发布前应在有 Chromium 的 CI 重跑。

## 标准贷款机催外部依赖（2026-10-07）

软件开发可继续；真实外呼尚缺电话 Provider 的派发/实时媒体契约、机构批准的身份核验方式、联系引用解析及测试号码授权。现有模型接入不等于实时电话对话已接通。生产账务快照和真实回款真实性需机构来源证明。当前新模块只有沙箱状态机联调；不能因已有服务连接标记而绕过上述缺口。

用户已明确授权每轮开发增量推送既有 GitHub 仓库并同步相关文档，无需逐轮确认。此授权不替代真实外呼、机构联系政策和生产业务启用所需的外部条件。

租户沙箱政策配置与执行复核已可开发联调，政策引用仍是管理员陈述。真实机构文件审核、真实渠道统一配额、媒体、本人核验及生产启用仍是外部依赖，不因政策保存成功而解除。

Linphone 可作为获准测试终端；主机 Docker 与 Linphone 账号/网络尚未在此环境具备，测试分机的真实注册和 RTP 验收待部署环境执行。公网手机外呼仍需运营商 SIP Trunk，完整 AI 通话仍需媒体/ASR/TTS 和业务授权关联。本轮继续软件工作，不把这些外部条件当作软件开发阻断。
