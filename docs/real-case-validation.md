# 真实案例验证

| 步骤 | 执行人 | 验收证据 |
|---|---|---|
| 部署真实后端并连接 Sites | 运维管理员 | v4.2 预检、生产环境、独立 Worker、企业登录 |
| 导入已获业务授权的脱敏案件 CSV | 操作员 | 版本化字段、来源摘要、委托与债权快照；不上传姓名、电话、身份证 |
| 独立复核导入并审批资产包策略 | 第二位管理员 | 提交者与复核者不同，策略版本已发布 |
| 在保护规则允许范围执行实际业务 | 已授权操作人员 | 实际 Provider 回执、人工确认记录；系统报告不授予执行权限 |
| 核对回执与不可变账簿 | 财务复核员 | 验签、到账/退款关联、净回款、独立对账 |
| 打开试点验收，输入案件编号 | 验收员 | 下载 case-validation-report.json，与外部银行/服务商凭证比对 |

CSV 字段与独立提交流程遵循既有资产导入手册。禁止把合成样本或模拟 Provider 成功当成真实案例通过。

报告中的“独立复核导入来源”仅证明软件记录可追溯，外部源文件真实性仍需业务方核实；“可核对回款证据链”仍需实际银行凭证比对。`real_business_verified` 始终为 false，自动检查不替代外部验收。

出现待处理项时，先处理来源、委托、策略或保护问题；不要通过改前端状态或账簿手动写入绕过门禁。跨租户案件返回 404，不导出客户身份与联系方式。
