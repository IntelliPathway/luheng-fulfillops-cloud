# v1.5 进展评估与后续优先级

## 总体判断

| 维度 | 评估 | 结论 |
|---|---:|---|
| 受控试点功能 | 90% | 主业务链、保护、复核、账务、Agent 门禁完整 |
| 数据与审计 | 90% | 服务端权威数据、不可变账簿和租户约束已成型 |
| 外部 Provider 实接 | 45% | 契约和门禁完成，真实 IdP/SIP/ASR/TTS/支付凭据未联调 |
| 生产运维 | 60% | 模板、健康、日志和指标完成，实际容量、备份、告警未验收 |
| 工程与安全 | 82% | 自动测试、迁移、安全头和默认关闭完成，仍缺 SAST/SBOM/容器扫描 |

综合结论：**v1.5 已达到受控试点代码基线，但不应宣称真实 Provider 或生产环境已上线。**

## v1.1–v1.5 交付摘要

| 版本 | 功能主题 | 提效代码 |
|---|---|---|
| v1.1 | 试点验收工作台 | 评分卡与指标并行载入 |
| v1.2 | 成员变更双人复核 | 成员/用户单次 join，避免 N+1 |
| v1.3 | 受控联系任务与人工接管 | 频次数据库聚合与复合索引 |
| v1.4 | 模型预算与支付异常运营 | 财务全表内存扫描改 SQL 聚合 |
| v1.5 | 查询规模与 API 安全 | 绑定筛选的游标分页和分面聚合 |
