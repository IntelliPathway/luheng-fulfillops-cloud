# v4.5.0 · 案例回款凭证比对

本轮将真实案例验收材料流程落到案件核对页面：可填写同一案件全部期间的外部凭证净额（整数分），服务端返回付款总额、退款总额、净回款与平台减外部的差异。金额一致仅代表手工输入与平台证据链一致，不证明凭证真实性或实际到账。

| 情况 | 比对结果 |
|---|---|
| 未填写外部净额 | 未提供，差异为空 |
| 缺少验签匹配的账簿证据链 | 不可用，差异为空 |
| 完整链且净额相同 | 金额一致，仍需外部独立复核 |
| 完整链且净额不同 | 显示整数分差异，排查付款与退款 |

改变案件、金额或租户会清除旧报告与下载入口；请求失败不保留旧成功结果。接口保持只读，无新数据库迁移、凭证原件上传、外呼或支付权限。

回归覆盖部分退款、零金额、差额、非法金额、跨租户、重复回执、错误签名、保护案件和报告下载/清理；沿用 15 个页面的 5 屏宽布局验收。

当前交付属于验收工具与合成案例回归。尚无真实企业 IdP、生产 API 或客户授权案例，真实业务验收仍未完成。
