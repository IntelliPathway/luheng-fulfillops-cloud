# 履约智控 AI · RepayGuard AI v1.5.0

## 目标

收口 v1.x 受控试点基线，强化大数据量列表查询、API 浏览器安全边界和迭代交付证据。

## 功能

- 案件目录新增与租户、筛选条件绑定的不透明游标。
- 保留旧页码分页契约，客户端可渐进迁移到游标。
- API 默认返回 `nosniff`、禁止 iframe、无 Referrer、禁止麦克风/摄像头/定位和不缓存策略。

## 提效改造

- 案件签约/保护分面从三次计数合并为一次条件聚合。
- 默认排序的首页和后续游标页不再使用深度 `OFFSET`，避免页数增长导致的扫描放大。
- 游标与筛选指纹绑定，防止错用旧游标导致数据窗口混淆。

## 验收

- 游标翻页无重复、顺序稳定；跨筛选条件复用游标返回 422。
- 现有页码分页、筛选、排序和分面契约保持兼容。
- 健康检查和业务 API 均包含统一安全头。

完整进展和后续优先级见 [v1.5 进展评估](../v1.5-progress-assessment.md)。
