# v5.0.0 集成验收发布

## 行为

将接入、同步、材料版本、关联复核、证据工作台、客户验收、Agent、账务和保护流程作为累计交付统一验收。试点页面增加集成报告，读取当前企业身份、来源、数据库迁移、Worker、租户状态、生产发布门禁及当前有效客户案例。扫描服务端全部已接受记录并重新核对有效性，不使用前端分页或历史状态计数。

报告刷新和导出都重新读取服务端；失败清除旧报告、禁用导出，跨租户响应不能显示。试点总览也在重读时清除旧指标，并忽略迟到响应。报告明确不代表外部真实性证明，不授予任何业务执行权限。

## 验证与运行

保留全部已有回归，增加集成报告范围、摘要、失效与只读测试；浏览器检查下载失败和真实报告。实际 dist 发布包通过 Sites Worker 验证 15 页面、五种宽度、品牌资产、CSP、API 503 演示契约及查询交互。PostgreSQL 演练使用隔离的随机数据库，执行全库备份恢复，核对加密原件、账务摘要、幂等与 33 个迁移，再运行已部署的 v4.15 代码验证回退兼容。

## 边界

当前 Sites 尚未配置生产后端、OIDC 和客户材料。软件集成测试使用合成数据及开发身份，不等于客户生产验收。正式身份、供应商、业务来源及恢复告警的独立审核仍须在客户部署环境完成。v5.0 无新增表迁移；应用回退不回退数据库结构或密钥。

## 企业化接入补完 · 2026-10-07

原子开通企业成员与套餐、停用身份阻断、真实工作空间发现、五步接入向导及标准模板、自托管 Keycloak 部署和公开配置生成。两家合成企业验证接入和权限隔离；实际服务器与身份服务未启动，授权客户验收未完成。详细范围见 [企业标准](../enterprise-onboarding.md)。
