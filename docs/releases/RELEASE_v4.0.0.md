# 履约智控 AI v4.0.0

## 交付主题

企业级多租户 SaaS 生命周期与可信 AI 商业闭环。

## 核心能力

- 租户支持 Trial、Active、Grace、Suspended、Closed 状态及受控转换。
- 生命周期记录合同/试点依据、部署区域、数据保留期和客户成功负责人。
- 所有状态变更采用管理员提案、另一管理员复核、乐观锁与审计事件。
- Suspended/Closed 自动暂停套餐权益，Agent 与高影响能力立即失败关闭。
- 组织设置展示企业生命周期版本和数据治理摘要。

## v3.1–v4.0 演进结果

- v3.1：套餐能力与资源配额强制执行。
- v3.2：不可变用量账本和自然月账单预览。
- v3.3：Phone、SMS、Email Provider 认证工作流。
- v3.4：Harness 插件注册、验证与证据驱动选型。
- v4.0：企业租户生命周期及商业控制联动。

## 验收边界

- 账单仍为核对预览，不自动扣款或开票。
- 真实 Provider 调用仍要求部署开关、白名单、外部密钥和合规批准。
- 企业 OIDC、域名、证书和真实 Provider 参数需要在目标环境完成最终 E2E。
