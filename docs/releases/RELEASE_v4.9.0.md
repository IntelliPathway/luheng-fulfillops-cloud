# v4.9.0 · 每日回执证据缺口定位

每日账簿新增回执证据筛选，可查看全部、已关联验签回执或证据待补全记录。失效记录明确显示缺少回执、验签未通过、未匹配入账、案件不一致或账簿反向关联不一致等原因。平台仅定位缺口，不自动修复或改账。

| 口径 | 说明 |
|---|---|
| `evidence_status` | `GET /api/v1/pilot/recovery-day` 新增可选参数 all / linked / incomplete，默认 all |
| `total` | 当前租户 UTC 日期内的整日账簿条数 |
| `filtered_total` | 当前证据筛选匹配条数，分页以此为准 |
| `evidence_gap` | 每条明细的首个证据缺口原因；完整记录为 null |
| 金额与比对 | 一直使用整日全部账簿及证据；只查看完整记录也不能绕过其他记录的缺口 |
| 无匹配记录 | 明确展示筛选为空，不能说整日无回款或把整日金额置零 |

筛选变更重置页码并清除旧结果，控件在读取期间保留；迟到响应不覆盖当前筛选。数据减少使页码超出当前筛选范围时自动回到有效页。失败可重试，不回退演示数据。移动端表格在弹窗内滚动，保持 BoardUI 工作台和原品牌。

回归覆盖合成签名付款/退款、五类证据缺口、SQL 空值、租户隔离、筛选分页、整日金额不变、比对不被筛选绕过、快速切换迟到响应及移动端布局。无新增依赖、配置项、迁移或账务写入。真实业务验收与外部执行仍未启用，客户生产材料待接入。
