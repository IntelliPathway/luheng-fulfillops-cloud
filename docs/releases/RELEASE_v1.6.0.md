# 履约智控 AI · RepayGuard AI v1.6.0

## 主题

在线业务权威化与 AI 指挥台。

## 功能

- 在线活动从服务端读取，暂停与恢复经过权限、保护状态和审计门禁。
- 审计记录提供租户隔离的查询与 CSV 导出。
- AI 指挥台聚合成员权限复核、受控联系任务和人工接管。

## 提效与体验

- 活动状态不再由浏览器和服务端分别维护。
- 审批、执行与证据集中展示，减少跨页面核对。
- 保持轻量 BoardUI 布局，以运行摘要、证据状态和下一动作强化 AI-native 体验。

## 验收

- 后端活动状态和审计查询测试通过。
- 前端 API 契约和生产构建通过。
