# 履约智控 AI · RepayGuard AI v1.1.0

## 目标

将 v1.0 的试点评分 API 转换为可操作的验收工作台，让交付人员不需组装多个接口即可判断阻断项。

## 功能

- 新增“试点验收”页面，聚合资产、运营、资金、复核队列和阻断项。
- 展示 API 请求总量、p50/p95 延迟和指标样本。
- Sites/离线模式明确不生成虚构验收结论。

## 提效改造

- 评分卡与运行指标并行请求，减少页面等待时间。
- 统一通过 `operationsApi` 访问运营验收数据，避免页面重复实现请求逻辑。

## 验收

- 租户切换后自动刷新证据。
- 管理员才能读取运行指标。
- 任一接口失败时页面明确报错，不回退为样本数据。
