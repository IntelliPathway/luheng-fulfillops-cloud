# v4.7.0 · 每日账簿明细与回执追溯

在线工作台的回款趋势可选择 UTC 日期并查看当日付款、退款、案件与账簿编号、应计佣金和回执关联状态。明细每页 20 条，整日净回款与佣金不随分页改变。移动端表格在弹窗内滚动，键盘可操作日期、分页、关闭与重试。

| 能力 | 口径与边界 |
|---|---|
| `GET /api/v1/pilot/recovery-day` | 认证租户、服务商事件 UTC 日期、只读不可变账簿；`day` 必填，`page` 默认 1，`page_size` 默认 20、最多 100 |
| 已关联验签回执 | 同租户、同案件、验签成功、已匹配、反向关联账簿编号正确 |
| 证据待补全 | 缺失或不满足上述关联；仍显示账簿金额，不伪称证据完整 |
| 整日金额 | 包含退款负值；当前页条数不是整日总数 |
| 真实业务验收 | 始终未认证；需要外部银行或服务商材料，不能由平台关联状态替代 |

切换日期、周期或租户清除旧明细；读取失败提供重试，不回退演示账簿。分页是实时读取，不承诺跨请求快照一致性。历史日期也可经只读 API 查询。

无新增依赖、配置项、账务写入或数据库迁移。服务端回归覆盖合成签名付款/退款、重复回执、UTC 日界、分页总额、租户隔离、失效回执与参数校验；浏览器覆盖分页、失败恢复、移动端布局和键盘关闭。真实企业生产接入与客户案例仍待外部条件提供。
