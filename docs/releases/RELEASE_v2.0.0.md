# 履约智控 AI · RepayGuard AI v2.0.0

## 主题

AI-native 跨域运营闭环。

## 产品能力

- AI 指挥台从服务端权威工作队列读取成员、策略、知识、履约方案、保护、联系、对账和支付异常。
- 队列按 P0—P3、SLA 与创建时间稳定排序；每项包含风险、证据、责任角色和处理入口。
- 界面明确呈现感知、推理、授权、执行四阶段，高影响动作仍由规则和人员审批决定。
- v1.6—v1.9 的在线活动、审计、通信恢复、知识治理、日终差异、SLO 和供应链门禁全部保留。

## 安全边界

- AI 只组织证据与建议，不越过 Maker–Checker、案件保护、渠道、频次、预算或账务门禁。
- 工作队列按租户构建，不包含原始支付载荷、电话号码、知识正文或凭据。

## 验收

- 跨域聚合、优先级、租户隔离与查看权限测试通过。
- UI 使用服务端队列，并为每项风险提供明确的证据去向。
