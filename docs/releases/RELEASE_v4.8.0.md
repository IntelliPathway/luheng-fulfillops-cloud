# v4.8.0 · 每日付款与退款双项核对

每日账簿弹窗分别展示当日付款与退款金额，并接受两项外部凭证金额（非负整数分，无退款填 0）。两项都一致才显示金额一致，不能仅凭净额一致掩盖抵消差异。

| 项目 | 判定口径 |
|---|---|
| 接口 | `GET /api/v1/pilot/recovery-day` 增加可选 `expected_payment_cents`、`expected_refund_cents`，两项必须同时提供或同时省略，范围 0–9007199254740991 |
| 差异 | 平台付款减外部付款、平台退款减外部退款；退款总额为正数 |
| 证据 | 当前租户整日所有回执都须满足同案件、验签、已匹配与账簿反向关联；不能仅检查当前页 |
| 无法比对 | 无账簿或证据链不完整时，状态为 unavailable，两项差异为 null |
| 核对摘要 | 只含日期、租户、整日汇总、关联计数与手工金额判定，不包含分页账簿明细 |
| 真业务验收 | 手工输入不是外部认证；externally_attested、real_business_verified 与 enables_external_execution 始终为 false |

输入变更立即清除原判定与下载入口，即使恢复原金额也需重新核对。日期、周期、租户或读取状态变化不得残留旧结果。核对只读，不改账、不执行支付、不保存原始凭证。分页仍是实时读取，不保证跨请求快照一致性。

回归覆盖签名付款/退款、零退款、两项差异抵消、分页外失效回执、空账簿、租户隔离、非法金额、摘要下载与失效、320px 移动端布局。无新增依赖、配置项或迁移。真实企业生产接入与客户凭证验收仍待外部材料提供。

API 对两项金额先校验规范 ASCII 十进制整数字符串，再转换为整数分；小数写法（包括 1.0、0.0）、科学计数法、符号、空白、前导零及非 ASCII 数字均拒绝。安全整数上限仍为 9007199254740991。
