# v4.10.0 · 客户材料接入与案件金额核对

试点验收新增客户材料工作台，支持 UTF-8 CSV 字段映射和 PDF / PNG / JPG 附件加密留存。Excel 需导出为 CSV；每份文件上限 1 MB，CSV 最多 50 个案件，每案一行历史累计付款及退款金额，单位为非负整数分。

| 能力 | 行为 |
|---|---|
| 原件留存 | AES-256-GCM 加密，以租户、来源摘要及映射摘要绑定；数据库不保存明文原件 |
| 字段映射 | 独立映射案件编号、付款分、退款分；只保存规范化案件编号与金额，其他列不进入规范化数据 |
| 去重 | 同租户相同内容、来源编号和映射返回同一材料；不同映射保留不同接入记录 |
| 金额核对 | 对已接入案件的全部历史账簿分别比对付款和退款，净额相等不能掩盖双项差异 |
| 证据失败 | 缺少验签或正确关联回执时差额为空；原件损坏或历史密钥不可用时报告失败 |
| 附件 | 仅留存与下载，不执行 OCR、不宣称真实性或签名已验证 |
| 权限 | 运营/管理员上传下载，成员读取材料摘要和核对报告，所有查询租户隔离 |

需要部署业务 API，并先应用 `028_customer_materials.sql`。加密复用 `SECRET_MASTER_KEY`、`SECRET_MASTER_KEY_VERSION` 与 `SECRET_PREVIOUS_KEYS`；未配置有效密钥返回 503，禁止明文降级。备份材料表时同时保留受控的历史密钥；轮换后保持旧密钥可解密。原件下载产生审计记录且不缓存，不在审计中记录正文。材料应已获客户授权并脱敏；来源编号与文件名也不得包含个人信息。

材料核对不创建案件、不写账、不授予执行权限。案件需先通过已有资产导入和独立管理员复核进入目录。核对结果标记金额一致、差异、证据不足或案件未接入，金额一致仍不构成客户验收。正式外部验收继续使用已有独立复核的试点验收记录。Sites 未连接业务 API 时仅可查看文件映射，不上传或留存材料。

回归使用合成材料与签名事件，覆盖加密往返、篡改、去重、租户隔离、权限、严格整数金额、双项比对、失效回执、附件边界及桌面/手机布局。真实客户生产材料未提供，不能宣称已完成客户现场验收。
