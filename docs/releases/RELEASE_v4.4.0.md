# v4.4.0 · 生产连接诊断与试点开通

- 新增租户范围只读连接诊断 API，联合检查生产配置、当前企业身份、请求来源、PostgreSQL/迁移、独立 Worker、两个管理员及租户激活。
- 试点验收增加诊断、重试、处理建议和 JSON 报告下载；失败时清除旧报告，未配置站点不能声称生产就绪。
- 技术接入与业务验收独立展示，报告不启用外部执行、不输出 Token、密钥或数据库连接串。
- 新增诊断权限/来源/就绪边界与浏览器导出、错误恢复、窄屏回归。无新增依赖与数据库迁移。
