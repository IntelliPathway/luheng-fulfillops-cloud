# v4.6.0 · 服务端回款趋势

在线工作台按近 7、30、90 天读取租户隔离的不可变回款账簿。趋势按服务商事件时间的 UTC 日期分组，付款为正、退款为负，每日整数分汇总；无账簿记录的日期显示 0。接口同时返回期间付款、退款、净回款和应计佣金。

| 界面金额 | 统计范围 |
|---|---|
| 顶部确认净回款 | 全工作空间、全部账簿期间 |
| 图表期间净回款 | 全工作空间、所选 UTC 日期窗口 |
| 柱图单位 | 元；负值表示该日退款超过付款 |

工作台资产包筛选用于案件列表，回款趋势始终标明全工作空间。读取失败展示不可用和重试，不能补入演示数据。切换周期和租户时清除旧结果，迟到响应不得覆盖新周期。

无新数据库迁移或依赖。回归覆盖 UTC 日界、未来日期排除、付款与退款汇总、重复回执、租户隔离、空日期和周期切换/失败恢复。保持现有 BoardUI 卡片布局与演示模式。

这是实际服务端数据统计能力；测试仍使用合成回执，真实企业部署及客户案例未完成。
