# 履约智控 AI v3.0.0

## 交付主题

商业化多租户控制面。

## 核心能力

- Pilot、Team、Enterprise 三档套餐的服务端权威权益、能力开关和资源限额。
- 按租户和自然月归集活跃席位、Agent Run、模型预算与托管案件。
- 套餐变更仅允许管理员执行，要求显式确认、乐观锁版本和审计事件。
- 用量与账单页统一呈现套餐、能力、配额状态和 AI 成本周期。

## v2.1–v3.0 演进结果

- v2.1：生产试点发布门禁与供应链安全扫描。
- v2.2：Phone、SMS、Email 多渠道安全沙箱。
- v2.3：Harness 目录、排行榜与证据驱动推荐。
- v2.4：受治理策略实验、稳定分流与回款归因。
- v3.0：商业化套餐、租户能力与用量控制面。

## 验收边界

本版本提供权威计量与权益控制，不包含自动扣款、发票或第三方支付代扣。真实渠道、模型与生产身份仍需通过既有发布门禁。
