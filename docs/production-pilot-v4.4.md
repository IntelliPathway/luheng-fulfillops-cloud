# v4.4 · 生产连接与试点开通

本轮完成只读连接诊断与可重复验收；实际生产资源尚未提供，当前 Sites 保持演示。

| 顺序 | 操作 | 核验依据 |
|---|---|---|
| 1 | 按现有 ECS/1Panel 模板部署 HTTPS API、私有 PostgreSQL 和独立 Worker | 生产配置禁止开发认证、自动建表与演示播种 |
| 2 | 执行版本迁移，使用 provision CLI 开通租户及两个独立企业管理员 | 迁移齐全、企业账号映射、成员权限与独立激活复核 |
| 3 | 配置 Sites 公开 API/OIDC 参数，以及后端和 IdP 的站点 allowlist | [接入参数](production-pilot-v4.2.md)；不填写客户端密钥或 Token |
| 4 | 从正式 Sites 完成企业登录，打开试点验收 → 生产连接诊断 | 当前企业身份、HTTPS 请求来源、生产配置、数据库、Worker、管理员与租户状态 |
| 5 | 下载 connection-readiness-report.json，完成跨域实测 | 浏览器 OPTIONS、授权查询、错误响应均可读；401/403 不降级为演示写入 |
| 6 | 演练 Worker 重启、过期租约恢复和 API 不可达 | 作业不丢失；配置后端失败时阻断写入，不回落本地样本 |
| 7 | 进入 v4.5 案例验收 | [真实案例材料](real-case-pilot-kit.md)，完成实际回执与外部凭证核对 |

接口：`GET /api/v1/pilot/connection-readiness`。必须有当前身份及租户成员权限；只读、no-store、不联网探测、不授予业务执行权限。只输出状态、非敏感来源与摘要，不输出数据库连接串、用户 sub、Token、密钥或完整服务配置。

`ready_for_pilot` 仅表示本次服务端技术条件具备；请求 Origin 只与服务端 allowlist 对比，不单独证明真实浏览器跨域成功。站点必须同时处于正式 API/OIDC 接入模式。业务联合验收状态单独列出，不能将技术条件通过当成真实案例通过。

部署前保存数据库备份、当前镜像标签与 Sites 运行时参数。故障时恢复已验证的镜像/站点版本；数据库恢复只在隔离环境演练，不自动覆盖生产库。实际 RPO/RTO、企业 IdP 和 Provider 联调由环境负责人记录。
