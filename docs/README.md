# 履衡 AI 文档中心

文档以当前 `main` 代码为准。发布说明记录“某一版本发生了什么”，稳定文档描述“系统现在如何工作”；不要把新的长期说明继续追加到历史发布文件或 `design-qa.md`。

| 文档 | 责任范围 | 更新触发条件 |
|---|---|---|
| [产品功能规格](product-functional-spec.md) | 角色、功能、流程、业务规则、验收 | 产品能力或业务状态机变化 |
| [系统架构](architecture.md) | 组件、模块、数据和信任边界 | 服务拆分、依赖或架构决策变化 |
| [配置参考](configuration.md) | 环境变量、默认值、敏感级别 | 新增、删除或修改运行配置 |
| [运维手册](operations-runbook.md) | 启停、发布、备份、故障处置 | 部署拓扑或运行流程变化 |
| [安全策略](../SECURITY.md) | 安全控制和报告流程 | 信任边界或安全门禁变化 |
| [贡献指南](../CONTRIBUTING.md) | 工程规范和质量门禁 | 工具链或协作方式变化 |
| [变更记录](../CHANGELOG.md) | 版本索引 | 每次发布 |

`design-qa.md` 和 `qa/` 是历史视觉验收证据，不作为当前产品规范的唯一来源。API 的机器可读契约以运行中的 `/api/openapi.json` 为准。
